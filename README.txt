MINI CASINO ONLINE — CHIP ẢO

Đây là bản thử nghiệm web game Poker 5 lá và Tài Xỉu, tối đa 8 người/phòng.
Chỉ dùng chip ảo, không nạp/rút hoặc quy đổi thành tiền thật.

CHẠY THỬ TRÊN MÁY CÓ NODE.JS 18+
1) Giải nén thư mục.
2) Mở terminal trong thư mục mini-casino-online.
3) Chạy: npm install
4) Chạy: npm start
5) Mở http://localhost:3000

TRIỂN KHAI ONLINE BẰNG GITHUB + RENDER
1) Tạo repository GitHub mới.
2) Upload toàn bộ NỘI DUNG bên trong thư mục mini-casino-online (gồm package.json, server.js, public/ và render.yaml).
3) Vào https://render.com, đăng nhập bằng GitHub.
4) Chọn New > Blueprint (nếu Render nhận render.yaml) hoặc New > Web Service.
5) Chọn repository vừa tạo và triển khai. Nếu tạo Web Service thủ công:
   - Runtime: Node
   - Build Command: npm install
   - Start Command: npm start
6) Chờ trạng thái Live, mở URL Render cấp và gửi cho bạn bè.

LƯU Ý QUAN TRỌNG
- Bản hiện tại lưu phòng và chip trong RAM. Khi máy chủ khởi động lại, phòng và số chip sẽ mất.
- Bản này phù hợp thử nghiệm với bạn bè, chưa có tài khoản, lưu trữ bền vững, chống gian lận hay kiểm thử bảo mật chuyên sâu.
- Không dùng tiền thật, không thêm nạp/rút tiền.
- Trên iPhone có thể tải ZIP, giải nén trong ứng dụng Tệp và upload từng file lên GitHub qua Safari; upload thư mục có thể cần chọn từng file.
